# FinRate Full Test

Тестовое приложение для учёта доходов, расходов, счетов и переводов. Месячная сводка показывает план и факт. Платежи, ожидаемые доходы и накопления связаны с тем же учётом.

Начальные остатки вымышлены. Используйте тестовые суммы. База хранится на устройстве в IndexedDB.

Исходники и проверки находятся в `source/`. Статические файлы в корне собираются с относительными ссылками для GitHub Pages. Команда `npm run build` из каталога `source/` записывает результат в `source/site/`.
