# FinRate Full Test

Первая сборка нового FinRate Full для проверки записи дохода и расхода. Интерфейс и переходы собраны по утверждённому образцу. Для хранения, расчёта остатков и записи операций используется финансовое ядро FinRate.

## Проверка

- Нажмите «Расход» или перетащите ползунок вверх. Введите сумму, выберите категорию, дату и счёт. Проверьте данные и сохраните.
- Нажмите «Доход» или перетащите ползунок вниз. Введите сумму, выберите категорию, дату и счёт. После сохранения откройте «Сводка» → «Получено».
- Откройте «Меню» → «Учёт» → «Операции». Проверьте запись, измените её или отмените. После перезапуска сохранённые записи остаются на устройстве.

Начальные остатки вымышлены. Используйте тестовые суммы. Платежи, переводы, настройка плана, накопления и резервные копии ждут следующих итераций.

Корень репозитория содержит готовую сборку для GitHub Pages. Исходники находятся в `source/`. Команды сборки и проверок: `npm run build` и `npm test`.
