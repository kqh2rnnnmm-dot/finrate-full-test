## Повторение

Из корня репозитория выполните:

```sh
cd source
npm install --no-package-lock
npm run build
npm run test:financial
npm test
FINRATE_REFERENCES=/путь/к/распакованному/UI_Lab npm run test:acceptance
```

Тесты Chromium поднимают приложение на `localhost` в подпапке `/finrate-full-test/`. Сценарий обновления читает статические файлы из Git по базовой ревизии и переключает ответы сервера на новую сборку. `FINRATE_REFERENCES` включает навигацию по эталону и парные снимки. Без этой переменной выполняется проверка приложения и обновления.

## Модель и совместимость

- План берёт ожидаемые поступления из расписаний, факт — из активных операций. Общий редактор применяет доли с текущего месяца. Сохранённые границы прошлых месяцев остаются доступны для просмотра.
- Подключены те же операции счёта и существующее защищённое хранилище IndexedDB. Настройки долей и цели добавляются по мере первого использования. Документ без новых полей принимается без пересоздания базы и без автоматического создания записей.
- Назначение в накопления хранится в общем документе и оставляет счёт неизменным. Цель связана с расходами через категорию. Закрытие фиксирует снимок и освобождает непотраченный остаток.
- Платёж и ожидаемый доход используют существующие связи ядра с фактическими операциями. Исправление и отмена используют тот же идентификатор факта.

## Короткая приёмка на iPhone

1. В светлой и тёмной темах проверить касания и оба свайпа на главной. Открыть меню, свернуть группы, вернуться и повторно открыть.
2. Записать вымышленные доход и расход с копейками на разные счета. Проверить клавиатуру, длинное имя, дату, заметку, предупреждение о черновике и возврат после отмены.
3. В сводке перейти на соседний месяц, открыть Получено и вернуться. Изменить долю категории. Открыть несколько целей и вернуться из плавающей истории в ту же позицию.
4. Провести перевод, покупку с кредитки, частичный платёж и связать ожидаемый доход с фактом. Сверить остатки и связанные записи после правки и отмены.
5. Перезагрузить страницу, затем повторить открытие после отключения сети.

Для выполнения пунктов 1–5 сборку потребуется открыть на тестовом HTTPS-адресе после подтверждения публикации.
